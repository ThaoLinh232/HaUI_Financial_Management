# 📱 Ứng Dụng Quản Lý Tài Chính Sinh Viên HaUI

**Mô tả:**
Ứng dụng giúp sinh viên Trường Đại học Công nghiệp Hà Nội (HaUI) quản lý tài chính cá nhân. Người dùng có thể theo dõi khoản thu, khoản chi, quản lý danh mục chi tiêu, và xuất báo cáo phân tích để lập kế hoạch chi tiêu hiệu quả.

---

## 🚀 Tính năng chính

* **Quản lý khoản thu/chi:** Thêm, sửa, xóa khoản thu và chi.
* **Quản lý danh mục:** Tạo, sửa, xóa danh mục chi tiêu.
* **Báo cáo phân tích:** Xem thống kê theo ngày, tuần, tháng.
* **Tìm kiếm nhanh:** Tìm khoản thu/chi theo từ khóa.
* **Xuất báo cáo:** Lưu báo cáo dưới dạng file (nếu có).
* **Giao diện thân thiện:** Dễ sử dụng cho sinh viên.

---

## 💻 Cài đặt & Chạy dự án

1. **Clone repository:**

```bash
git clone https://github.com/ThaoLinh232/HaUI_Financial_Management
```

## ⚙️ Công nghệ sử dụng

* **Ngôn ngữ:** Java
* **IDE:** Android Studio
* **Cơ sở dữ liệu:** Firebase
* **Quản lý phiên bản:** Git

---

## 📝 Hướng dẫn sử dụng

1. Mở ứng dụng → Đăng nhập/Đăng ký (nếu có)
2. Thêm danh mục chi tiêu → Thêm khoản thu/chi
3. Xem báo cáo phân tích → Xuất báo cáo
